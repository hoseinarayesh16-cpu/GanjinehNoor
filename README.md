# گنجینه نور v1.4 — پروژه اندروید (نسخه توسعه‌ای)

## افزوده‌های واقعی
- نام فارسی همه ۱۱۴ سوره به جای شماره خالی.
- دریافت ترجمه فارسی سوره‌ها از API عمومی AlQuran Cloud (شناسه fa.makarem) و ذخیره موقت محلی در WebView.
- متن عربی ۱۱۴ سوره به‌صورت آنلاین با ذخیره موقت، پخش آنلاین سوره‌ها با انتخاب قاری، و انتخاب فایل صوتی محلی.
- حفظ امکانات نسخه قبل: علاقه‌مندی، اندازه خط، دسته‌بندی، جست‌وجو و نمونه متن دعاها.

## محدودیت‌ها
- ترجمه فارسی ممکن است مشمول حقوق نشر باشد؛ پیش از انتشار عمومی باید مجوز ناشر ترجمه و مجوز صوت بررسی شود.
- محتوای مفاتیح و زیارت‌ها هنوز نمونه است؛ ادعای تکمیل نداریم.
- صوت مداحان دعاها بسته‌بندی نشده و کاربر باید فایل مجاز انتخاب کند.
- نیازمند Android Studio/Android SDK برای ساخت APK؛ در این محیط APK ساخته یا روی گوشی آزمایش نشده است.
- سرویس خارجی ممکن است قطع یا تغییر کند. داده‌های دریافت‌شده تنها در صورت اتصال موفق در دسترس‌اند.
